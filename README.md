Sample Superstore Exploratory Data Analysis (EDA)

An end-to-end Python data analysis project targeting retail performance across 9,994 orders. This project cleans and profiles sales metrics, identifies peak seasonality and loss-making discount thresholds, and generates an automated executive PDF report with actionable business recommendations.

Key Highlights to Feature in your README:

Tech Stack: Python, Pandas, NumPy, Matplotlib, Seaborn,Scikit Learn

Core Focus: Data Cleaning (IQR Median Imputation), Statistical Profiling, Data Visualization, Pricing & Discount Analysis, and Seasonal Trend Forecasting

Output: Jupyter Notebook (.ipynb) and an Executive Summary PDF Report
